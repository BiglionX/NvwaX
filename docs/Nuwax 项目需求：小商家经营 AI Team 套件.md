2. 每个 Agent 的能力定义
内容创作 Agent：

输入：商品信息、行业关键词、目标平台（抖音/小红书/视频号）

输出：符合平台风格的文案（小红书种草风、抖音快节奏脚本） + 图片/视频剪辑建议（可调用剪映 API 或生成数字人视频）

使用 DeepSeek 模型 + 本地模板库

社媒发布 Agent：

支持定时发布、多账号管理

自动添加话题标签、@官方号

发布后返回链接和状态

客服互动 Agent：

通过 Webhook 接收社媒私信/评论

使用大模型生成回复（可设置自动或人工审核）

支持常见问题知识库（商家可导入 FAQ）

数据分析 Agent：

每日拉取各平台数据：播放量、点赞、评论、分享、粉丝增长

生成可读报告：“本周最热视频是 X，建议继续发布类似内容”

团单管理 Agent：

从美团/闪购拉取当前活动团单

支持一键更新价格/库存（调用平台 API）

订单监控 Agent：

长轮询或 Webhook 接收新订单

桌面端弹出醒目通知（包含商品、金额、配送地址）

支持语音朗读：“您有一笔新订单，请及时处理”

进销存同步 Agent：

订单产生后自动减少本地库存

当库存低于阈值时，自动向采购 Agent（可选）发起补货建议

静/动销分析 Agent：

分析指定周期内（如 30 天）每个商品的销售频率

静销品：标记为“滞销”，建议降价或下架

动销品：标记为“热卖”，建议增加备货或推出组合套餐

商品上架 Agent：

读取本地商品表，转换为小程序商城所需格式

调用小程序云开发 API 批量上传

支持增量同步（价格/库存变动时自动更新）

订单同步 Agent：

监听小程序商城的订单创建 webhook

转换订单格式，写入本地销售单

自动扣减库存

客户管理 Agent：

整合来自社媒、团购、小程序的客户信息

自动打标签（如“抖音粉丝”、“高频复购”）

支持批量发送促销消息（需商家确认）

3. 安装与配置流程（在 Nuwax 上）
商家在 ProClaw-Light 桌面端点击“市场” → 选择“MicroBiz AI Team Suite”

弹出引导对话框：

第一步：选择要启用的 Team（可多选：新媒体/团购/小程序）

第二步：为每个 Team 绑定账号（如抖音授权、美团商家账号、小程序 AppID）

第三步：设置运营偏好（如内容发布时间段、订单通知方式）

完成安装，Agent 自动开始工作

4. 技术实现要点
API 集成：需要封装抖音、小红书、美团、闪购、微信小程序的官方 API（可使用第三方聚合服务如 Apifox 来简化）

本地回调：ProClaw-Light 需暴露 webhook 地址给云端平台，用于接收订单推送

语音通知：桌面端 Tauri 调用系统 TTS 或播放预录语音

数据本地化：所有经营数据仅存储在商家本地 SQLite，不上传云（除非开启 Pro 版备份）
